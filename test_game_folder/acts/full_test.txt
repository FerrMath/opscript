CHOICE INTEGRATION TESTS

This file assumes the variable set_test already exists.
The tests reset it when needed.

==================================================
TEST 1 - BASIC CHOICE AND RETURN TO NORMAL FLOW
==================================================

#choice
    *option Pick A
        TEST 1: Picked A.
    *option Pick B
        TEST 1: Picked B.
    *option Pick C
        TEST 1: Picked C.

TEST 1 PASS POINT: This text must appear after the selected option.

TEST 2 - MULTIPLE LINES INSIDE ONE OPTION
==================================================

        TEST 2: Line 3.

TEST 2 PASS POINT: Execution returned after the option.

TEST 3 - NESTED CHOICE
==================================================

            *option Nested B

        TEST 3: Returned to the outer option after nested choice.

    *option Skip nested choice

==================================================

        TEST 4: Returned from level 2 choice.

        TEST 4: Deep nesting skipped.

TEST 4 PASS POINT: Deep nesting finished correctly.

==================================================
TEST 6 - CHOICE -> SET -> IF / ELIF / ELSE
==================================================

        #set set_test = 1
    *option Set value to 2
        #set set_test = 2
    *option Set value to 3
        #set set_test = 3

#if ${set_test} == 1
    TEST 6 PASS: IF branch detected value 1.

    TEST 6 PASS: ELIF branch detected value 2.

    TEST 6 PASS: ELSE branch detected value ${set_test}.

TEST 6 PASS POINT: Conditional finished and execution continued.


==================================================
TEST 7 - IF -> CHOICE
==================================================

#set set_test = 1

#if ${set_test} == 1
    TEST 7: Condition entered.

    #choice
        *option Conditional option A
            TEST 7: Conditional A selected.
        *option Conditional option B
            TEST 7: Conditional B selected.

    TEST 7: Returned inside the IF after the choice.
#else
    TEST 7 FAIL: This branch should not run.

TEST 7 PASS POINT: Execution returned outside the IF.

==================================================
TEST 11 - GOTO BACK TO A CHOICE WITH UPDATED VARIABLE
==================================================

#set set_test = 0

#bookmark repeated_choice
TEST 11: Current value before choice = ${set_test}

#choice
    *option Add 1 and repeat
        #set set_test = ${set_test} + 1
        TEST 11: Updated value before goto = ${set_test}
        #goto repeated_choice

    *option Subtract 1 and repeat
        #set set_test = ${set_test} - 1
        TEST 11: Updated value before goto = ${set_test}
        #goto repeated_choice

    *option Exit repeated choice
        TEST 11: Leaving repeated choice with value ${set_test}.

TEST 11 PASS POINT: Final repeated-choice value = ${set_test}
